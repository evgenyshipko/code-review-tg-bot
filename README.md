## Телеграм-бот для код-ревью

### Запуск
1. Через @BotFather в telegram создать нового бота
2. Создать .env файл в корне и заполнить его значениями по примеру из .env.sample
3. Запустить бота ```go build code-review-tg-bot/src/main```

### Как пользоваться?
* добавить бота в чат телеграма и наделить его админскими правами
* тегать бота в сообщении с ссылкой на ваш merge-request

### Возможности бота:
* проставляет ревьверов из пересечения двух списков: участники чата, в котором состоит бот, и REVIEW_PARTICIPANTS_IDS
![default.png](images/default.png)
* запоминает кто делал ревью последний раз и раздает его другим, итеративно ходит по списку участников чата
* если в merge request есть конфликты, то не дает отдать бота на ревью
![conflicts.png](images/conflicts.png)
* если в merge request строк больше, чем значение переменной MAXIMUM_ROWS_CHANGED, то не дает отдать в ревью
![bounds.png](images/bounds.png)
